How this website calculates the global-derived value
Global metal price is quoted in USD per troy ounce. The website converts it to BDT using USD/BDT, converts troy ounce to grams, and then applies the selected purity.
1 troy oz = 31.1034768 g  •  1 bhori = 11.664 g
